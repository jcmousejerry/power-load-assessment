# 异常仿真调控与 AI Agent 使用说明

## 先用一句话理解两个功能

- “异常影响与备用供电”：你自己分析异常、选择安全备用路径，并在图上亲手完成一次备用供电切换演练。
- “AI 异常处置 Agent”：你只告诉 Agent 要处理哪台设备；模型会观察每次工具结果再决定下一步。你授权后，它还会跑完正式仿真并亲自完成五步仿真调控。

这里的“断开开关、接通线路、转移负荷”全部发生在系统仿真中，不会控制真实电网设备。

## 功能一怎么用

### 入口

最直接的入口是左侧“变压器实时监控”。找到一台设备，在“下一步”一列点击“影响分析”。系统会自动带入设备编号。也可以直接打开左侧“异常影响与备用供电”，再从下拉框选择设备。

### 第一步：自动分析

1. 选择异常设备。
2. 选择模拟时长，通常保持“一小时”。
3. 点击“第2步：一键分析影响和备用方案”。
4. 等待进度达到 100%。

完成后页面会告诉你受影响区域、需要转移多少 kW、找到几条备用路径，以及每条路径是“安全线内，可以使用”还是“可能过载，不建议使用”。点击任意方案卡片，拓扑图会切换到那条路径。灰色是异常设备，绿色是建议路径，黄色/红色代表负载偏高。

### 第二步：亲手做仿真调控

只有绿色“可以使用”的方案才会显示“进入手动仿真调控台”。点击后按页面给出的唯一下一步操作：

1. “确认并开始”：锁定本次设备和安全路径。
2. “断开原线路”：异常设备在图上变灰，供电状态提示等待备用线路接管。
3. “接通备用线路”：黄色虚线变成绿色实线。
4. “转移负荷”：目标设备显示增加后的 kW 和负载率，受影响区域变为备用供电。
5. “核验结果”：确认最高负载率没有超过安全线，演练完成。

每次点击都会弹出确认框。页面不允许跳步。如果不想继续，点击“撤销并恢复”，拓扑会恢复为原线路接通、备用线路断开的状态。

页面底部“操作记录”会永久保存每一步的操作人和时间。刷新页面、关闭浏览器或重启项目后仍然可以查看。

## 功能二怎么用

### 入口和任务目标

从“变压器实时监控”点击“AI帮我处理”，或打开左侧“AI 异常处置 Agent”。

1. 选择设备。
2. 选择“快速恢复”“两小时保守检查”或“完整比较路径”。
3. 如有需要，在补充要求中写一句普通话，例如“优先选择负载最低的备用设备”。
4. 点击“交给Agent执行调查”。

### Agent 调查时你会看到什么

右侧“Agent任务工作台”不是聊天记录，而是实时任务轨迹。它会核实实时负载、预警和趋势，追踪设备连接，计算影响，生成路径，逐条预演并交叉核验安全条件。

每一步有“执行中、已完成或失败”状态，页面也显示工具调用数量和 Token 用量。运行中可以点击“取消本次任务”。

### 为什么会出现授权卡

查数据和做临时计算不会改业务数据，所以 Agent 自动执行。创建正式处置任务属于写操作，因此页面会出现“一次性授权”卡。

- 点击“拒绝，只保留调查结果”：Agent 停止，数据库不创建正式处置任务。
- 点击“授权Agent执行本次任务”：只授权当前这一次任务。

### 授权后 Agent 会替你完成什么

Agent 会继续在后台创建正式异常处置任务、运行全部路径的逐时仿真、等待所有结果并选择风险最低的安全方案。随后它会严格按照后端允许的安全顺序，依次完成确认、隔离原线路、接通备用线路、转移负荷和结果核验。

工作完成后页面会明确显示五项动作是否完成、最终核验是否通过。点击“查看正式方案与Agent调控记录”可以检查仿真曲线、每项动作和操作前后状态，不需要再手动重复执行。

## 常见问题

### 这会不会真的断电？

不会。当前项目没有真实设备控制接口，所有开关和负荷变化只存在于仿真数据库和拓扑图。

### 为什么有时不能进入调控台？

只有正式仿真完成且未超过安全线的方案才能进入。如果所有路径都可能过载，系统会停止，不允许通过前端绕过。

### 页面刷新后任务没了吗？

不会。分析任务、Agent运行步骤、审批、仿真进度、调控状态和操作记录都保存在 MySQL；逐时负荷结果也持久化保存。

### Agent 和普通“一键分析”有什么实际差别？

普通功能由你生成候选、逐个启动仿真、选择方案并点击五次完成调控。Agent 模式中，模型会逐轮选择调查工具；经一次授权后，它会继续决定并执行正式任务、全部仿真、方案选择和五项调控动作。界面把“模型自主决定”和“实际工具调用”分开显示，因此可以核对它是否真的完成了工作。

```powershell
.\scripts\Stop-Project.ps1
```
