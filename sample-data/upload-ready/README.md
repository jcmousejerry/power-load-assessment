# LoadFlex 前端上传测试数据集

本目录中的五个数据集都可以在“数据集中心 → 上传数据”中直接选择。所有文件都使用系统能够自动识别的标准字段，上传后无需填写字段映射，可以直接创建分析流水线。

## 文件说明

| 文件 | 布局 | 规模 | 适合验证 |
|---|---|---|---|
| `01_standard_long_12users_30days.csv` | 标准长表 | 12用户、30天、15分钟、34,560行 | 推荐首先使用；验证完整流水线、用户聚类和各集群预测 |
| `02_standard_wide_9users_30days.csv` | P1-P96宽表 | 9用户、30天、270行，展开后25,920点 | 验证宽表自动识别和转换 |
| `03_aggregate_long_60days.csv` | 无用户字段的聚合长表 | 1条聚合曲线、60天、5,760行 | 验证聚合数据按日曲线聚类 |
| `04_quality_check_with_minor_issues.csv` | 带少量质量问题的长表 | 8用户、14天、10,698行 | 验证缺失、重复和无效行检测；仍可完成整条流水线 |
| `05_standard_long_6users_21days.xlsx` | Excel标准长表 | 6用户、21天、12,096行 | 验证XLSX上传；第一个工作表是数据，第二个是说明 |

## 自动识别规则

- 长表字段：`user_id`、`timestamp`、`load_kw`
- 宽表字段：`user_id`、`date`、`P1` 至 `P96`
- 原始单位：kW
- 采样间隔：15分钟，可由系统自动推断

## 建议操作

1. 上传文件并填写一个未使用过的数据集名称。
2. 不需要点击“字段映射”。
3. 进入任务中心，点击“创建分析流水线”。
4. 选择刚上传的数据集，聚类数量建议使用3。
5. 在任务中心观察依赖顺序，在分析结果中查看各集群结果。

`VALIDATION_REPORT.json`记录了每个文件使用项目自身算法读取和执行后的验证指标。五个文件均已通过数据标准化、质量检查、特征提取、三集群聚类、预测、基线和潜力计算。
